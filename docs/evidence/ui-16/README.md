# UI foundation evidence

These screenshots document the test-only `/ui-foundation-preview` route for Issue #16. The route is available only when `NEXT_PUBLIC_E2E_TEST=true`; a normal production build returns 404.

- `foundation-light-desktop.png` — 1440 px desktop, explicit light theme.
- `foundation-dark-tablet.png` — 1024 px tablet, explicit dark theme.
- `foundation-system-mobile-dialog.png` — 390 × 844 px mobile viewport, system dark preference, dialog open after its entrance transition.

The preview uses sample Vietnamese copy and does not read or write product data.
