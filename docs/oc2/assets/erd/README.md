# OC2 ERD exports

This directory keeps versioned visual exports of the migration-derived Outcome 2 data model.

## Current draft

- [`fitsync-oc2-data-model-draft.svg`](fitsync-oc2-data-model-draft.svg): vector Mermaid export.
- [`fitsync-oc2-data-model-draft.png`](fitsync-oc2-data-model-draft.png): 5610 x 8192 px raster export.
- Canonical editable source: [`../../FITSYNC_OC2_ERD.mmd`](../../FITSYNC_OC2_ERD.mmd).

The diagram covers all eight OC2 tables and their primary relationships. It is intentionally labelled `draft` until the required title, footer, external Auth/private-storage elements, five security callouts, PDF export, migration cross-review, and view-only Drive link are complete.

Do not add credentials, signed URLs, private object paths, or real health records to any export.
